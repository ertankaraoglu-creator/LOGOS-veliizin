# LOGOS Veli İzin Dilekçesi

Veli izin dilekçesini ve öğrenci belgesini tek tıkla hazırlayan, idarecinin bilgisayarında çalışan ücretsiz masaüstü uygulaması
(LOGOS Ders Dağıtım ve LOGOS Disiplin'in kardeşi). Veli gelir, idareci öğrenciyi seçer, veli adı kendiliğinden gelir, takvimden günler
işaretlenir, dilekçe yazıcıdan çıkar; veli imzalar. Kayıtlar ve istatistik yıl boyunca birikir.

- Öğrenciler e-Okul'un **Genel Öğrenci Listesi** PDF'lerinden (Ortaöğretim Öğrenci İşlemleri › Yazdır › OOG01001R092) gelir; kimlik
  numaraları **Fotoğraflı-Kimlik Bilgili Öğrenci Listesi**nden; fotoğraflar yalnız istenirse.
- Dilekçe: geriye dönük özür beyanı ya da ileriye dönük izin isteği; tam gün / yarım gün; "Diğer" kişiye teslim (ad, yakınlık, kimlik no, telefon).
- Öğrenci belgesi: e-Okul düzeninde, eksik alanlar elle doldurulur.
- Bütün veri bu bilgisayarda, şifreli kasada (`.lvk`); program internete çıkmaz.

Çalıştırma: `pip install -r requirements.txt` → `python -m uygulama.ana` (pencere) ya da `python -m uygulama.ana --tarayici 8767`.
Sınamalar: `sinama/README.md`. Çalışma kuralları: `CLAUDE.md`.
